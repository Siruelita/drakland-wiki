# Travesuras de Nathair

*Ilusión · Nivel 2*

> [!spell] Datos
> **Nivel:** 2
> **Escuela:** Ilusión
> **Tiempo de lanzamiento:** 1 acción
> **Alcance:** 60 pies
> **Duración:** Concentración, hasta 1 minuto
> **Componentes:** S, M
> **Concentración:** Sí
> **Resolución:** TS Sabiduría / TS Destreza / Sin tirada
> **Clases:** Bardo, Hechicero, Mago

## Descripción

Llenas un **cubo de 20 pies de lado** que puedas ver dentro del alcance con una mezcla de magia feérica y dracónica.

Al lanzar el conjuro, tira **1d4** para determinar qué efecto mágico se produce.

Mientras dure el conjuro, debes volver a tirar **1d4 al comienzo de cada uno de tus turnos** para determinar el nuevo efecto.

Antes de realizar cada una de estas tiradas, puedes **desplazar el cubo hasta 10 pies**.

## Efectos mágicos

Tira **1d4** y aplica el resultado correspondiente.

| 1d4 | Efecto |
|---|---|
| 1 | Aroma de pastel de manzana |
| 2 | Flores deslumbrantes |
| 3 | Risa incontrolable |
| 4 | Gotas de melaza |

### 1. Aroma de pastel de manzana

El área se llena con el aroma de un pastel de manzana.

Cada criatura dentro del cubo debe realizar una **tirada de salvación de Sabiduría**.

- **Fallo:** queda **hechizada por ti** hasta el comienzo de tu siguiente turno.
- **Éxito:** no queda hechizada.

### 2. Flores deslumbrantes

Aparecen numerosos ramos de flores que rocían agua sobre los rostros de las criaturas.

Cada criatura dentro del cubo debe realizar una **tirada de salvación de Destreza**.

- **Fallo:** queda **cegada** hasta el comienzo de tu siguiente turno.
- **Éxito:** no queda cegada.

### 3. Risa incontrolable

Una influencia mágica provoca ataques de risa.

Cada criatura dentro del cubo debe realizar una **tirada de salvación de Sabiduría**.

- **Fallo:** comienza a reír de manera incontrolable hasta el comienzo de tu siguiente turno.
- **Éxito:** no queda afectada.

Mientras una criatura esté afectada por esta risa:

- Queda **incapacitada**.
- Debe utilizar **todo su movimiento para desplazarse en una dirección aleatoria**.

### 4. Gotas de melaza

Aparecen gotas de melaza que permanecen suspendidas en el aire dentro del cubo.

Toda el área se convierte en **terreno difícil** hasta el comienzo de tu siguiente turno.

Este efecto no requiere tirada de salvación.

### Componentes materiales

Necesitas **un trozo de corteza de un pastel de manzana**.

## A niveles superiores

Este conjuro no obtiene beneficios adicionales al utilizar espacios de nivel superior.
