# Llama sagrada

*Evocación · Truco*

> [!spell] Datos
> **Nivel:** Truco
> **Escuela:** Evocación
> **Tiempo de lanzamiento:** 1 acción
> **Alcance:** 60 pies
> **Duración:** Instantáneo
> **Componentes:** V, S
> **Concentración:** No
> **Resolución:** TS Destreza
> **Clases:** Clérigo

## Descripción

Una luminosidad similar a una llama desciende sobre una criatura que puedas ver dentro del alcance.

El objetivo debe superar una **tirada de salvación de Destreza** o recibir **1d8 de daño radiante**.

El objetivo **no obtiene beneficio de cobertura** para esta tirada de salvación.

## Escalado

El daño aumenta al alcanzar determinados niveles:

- Nivel 5: **2d8**
- Nivel 11: **3d8**
- Nivel 17: **4d8**

## Fuente

**SRD 5.1**

Nombre original: Sacred Flame
