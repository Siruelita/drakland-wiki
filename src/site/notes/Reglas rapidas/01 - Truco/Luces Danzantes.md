# Luces danzantes

*Evocación · Truco*

> [!spell] Datos
> **Nivel:** Truco
> **Escuela:** Evocación
> **Tiempo de lanzamiento:** 1 acción
> **Alcance:** 120 pies
> **Duración:** Concentración, hasta 1 minuto
> **Componentes:** V, S, M
> **Concentración:** Sí
> **Resolución:** Sin tirada
> **Clases:** Bardo, Hechicero, Mago

## Descripción

Creas hasta **cuatro luces** del tamaño aproximado de una antorcha dentro del alcance.

Cada luz puede adoptar la apariencia de una antorcha, una linterna o una esfera luminosa. También puedes combinar las cuatro luces para crear una forma luminosa vagamente humanoide.

Cada luz emite una iluminación tenue en un radio de **10 pies**.

Las luces deben permanecer a un máximo de **20 pies** unas de otras.

Como acción durante tus turnos, puedes mover las luces hasta **60 pies** a una nueva posición dentro del alcance del conjuro.

Si una luz supera la distancia permitida respecto de las demás, desaparece.

## Escalado

Este truco **no aumenta su potencia con el nivel**.

## Fuente

**SRD 5.1**

Nombre original: Dancing Lights
