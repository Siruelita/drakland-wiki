# Inmovilizar monstruo

*Encantamiento · Nivel 5*

> [!spell] Datos
> **Nivel:** 5
> **Escuela:** Encantamiento
> **Tiempo de lanzamiento:** 1 acción
> **Alcance:** 90 pies
> **Duración:** Concentración, hasta 1 minuto
> **Componentes:** V, S, M
> **Concentración:** Sí
> **Resolución:** TS Sabiduría
> **Clases:** Bardo, Brujo, Hechicero, Mago

## Descripción

Eliges una criatura que puedas ver dentro del alcance.

El objetivo debe realizar una **tirada de salvación de Sabiduría**.

Si falla, queda **paralizado** mientras dure el conjuro.

Este conjuro **no tiene efecto sobre muertos vivientes**.

Al final de cada uno de sus turnos, el objetivo puede repetir la tirada de salvación de Sabiduría.

Si tiene éxito, el conjuro termina sobre él.

## A niveles superiores

Cuando utilizas un espacio de conjuro de nivel 6 o superior, puedes afectar a **una criatura adicional por cada nivel del espacio por encima de 5**.

Todas las criaturas elegidas deben encontrarse a **30 pies o menos entre sí** cuando lanzas el conjuro.

- Nivel 5: **1 criatura**
- Nivel 6: **2 criaturas**
- Nivel 7: **3 criaturas**
- Nivel 8: **4 criaturas**
- Nivel 9: **5 criaturas**
